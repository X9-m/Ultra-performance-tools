## Overview

**3AKED Ultra Performance Tools** is a Windows CMD-based utility designed to improve the performance of weak or low-end Windows PCs.

The tool focuses on safe performance optimization without disabling core Windows security features.

## Main Features

The tool includes the following sections:

1. **Ultra Performance Boost**  
   Runs all safe performance optimizations at once.

2. **Clean Temp and Cache**  
   Deletes temporary files and common Windows cache files.

3. **Close Heavy Processes**  
   Closes common heavy background applications such as browsers, game launchers, chat apps, and similar processes.

4. **Visual Performance Mode**  
   Reduces animations, transparency, and some Windows visual effects.

5. **Power Plan Optimizer**  
   Enables **Ultimate Performance** if available, otherwise attempts to use **High Performance**.

6. **System Information**  
   Displays basic device information such as CPU, RAM, disk information, Windows version, and active power plan.

7. **Fun Zone**  
   Includes terminal-style entertainment such as a small train animation and loading animation.

8. **Contact Info**  
   Displays developer contact information.

9. **Documentation**  
   Shows built-in documentation inside the tool.

10. **Restore / Restart Services**  
   Restarts optional services and Windows Explorer.

## Safety Notes

This tool is designed to be safe for normal users.

It does **not**:

- Disable Windows Defender.
- Disable Windows Firewall.
- Delete personal files.
- Delete desktop files.
- Delete documents, pictures, videos, or downloads.
- Permanently damage Windows services.

Some changes are temporary and may return after restarting Windows.

---

## What Ultra Performance Boost Does

When selecting option `[1] Ultra Performance Boost`, the tool performs these actions:

- Activates Ultimate Performance or High Performance power plan.
- Reduces Windows animations and transparency.
- Closes common heavy applications.
- Temporarily stops optional heavy services:
  - SysMain
  - Windows Search
- Cleans:
  - User TEMP folder
  - Windows TEMP folder
  - Recent files cache
  - Prefetch cache
  - DNS cache
- Restarts Windows Explorer.

## Recommended Usage

For weak PCs, use this order:

1. Run option `[1] Ultra Performance Boost`.
2. Restart the computer.
3. Use the PC normally.
4. If you want to restore services, run option `[R] Restore / Restart Services`.

## Troubleshooting

### Problem: The tool shows strange characters

Make sure you are using the **V2 Stable** version.

The stable version avoids broken CMD color codes and Unicode parsing issues.

---

### Problem: CMD says some commands are not recognized

This usually happens if:

- The old version was used.
- The file was copied incorrectly.
- The script was pasted directly into CMD instead of being saved as `.bat`.

Solution:

- Do not paste the code directly into CMD.
- Download the `.bat` file and run it as a file.

---

### Problem: The tool closes some apps

This is expected when using performance options.

The tool closes common heavy applications such as:

- Browsers
- Discord
- Steam
- Teams
- Telegram
- WhatsApp
- Zoom
- Game Bar
- Launchers

Save your work before running performance mode.

---

### Problem: Some settings return after restart

Some services and background processes may start again after restarting Windows.  
This is normal Windows behavior.

Run the tool again when needed.
